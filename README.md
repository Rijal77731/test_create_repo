# 📊 E-Commerce Sales Dashboard

## 📌 Project Overview
This project is an interactive E-Commerce Sales Dashboard built to analyze sales performance, customer behavior, and product insights. The dashboard helps businesses monitor key metrics, identify best-selling products, evaluate promotions, and understand customer demographics for better decision-making.

---

## 🎯 Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Monitor the impact of promotions and discounts.
- Understand customer demographics.
- Discover purchasing trends over time.

---

## 📂 Dataset Information
The dataset contains **1,000 e-commerce transactions** with the following attributes:

| Column | Description |
|---------|-------------|
| ProductID | Unique product identifier |
| ProductName | Product name |
| Category | Product category |
| Price | Product price |
| QuantitySold | Quantity purchased |
| Promotion | Promotion applied (Yes/No) |
| Discount | Discount percentage |
| Rating | Customer rating |
| CustomerAge | Customer age |
| CustomerGender | Customer gender |
| CustomerLocation | Customer location |
| PurchaseDate | Transaction date |

---

## 📈 Dashboard Features

The dashboard includes:

- 💰 Total Sales
- 📦 Total Quantity Sold
- ⭐ Average Product Rating
- 🏆 Top Selling Products
- 📊 Sales by Category
- 🌍 Sales by Customer Location
- 👥 Customer Demographics
- 🎁 Promotion vs Non-Promotion Sales
- 📅 Sales Trend Over Time

## 📊 Key Insights

Some insights that can be obtained from the dashboard include:

- Identify the product categories with the highest sales.
